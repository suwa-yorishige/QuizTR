# QuizTR

早押しクイズ形式で知識を定着させる、ブラウザ完結型の学習アプリです。問題のCSV取り込み、AIによる問題生成・解説補完、読み上げ辞書、MP3音声作成、正解率に応じた復習などを1つの `index.html` で利用できます。

## 特徴

- **早押しクイズ学習**  
  ブラウザの音声合成で問題を読み上げ、早押しボタンで回答フェーズに進みます。ダッシュボードの「確定ポイントモード」を有効にすると、音声・文章モードのどちらも問題ごとの確定ポイントまで出題します。この設定は保存されます。

- **学習セット管理**  
  複数の学習セットを作成し、セットごとに問題を管理できます。「問題管理」の「セット統合」では、2つのセットを選び、問題を移動して統合できます。統合後のセット名には統合先の名前が初期入力され、統合先を変更するとその名前に更新されます。

- **CSV取り込み**  
  問題文・解答・解説をCSVから一括登録できます。UTF-8 / Shift-JISの読み込みに対応しています。

- **AI問題生成**  
  Gemini APIを利用して、ジャンル・サブジャンル・難易度を指定したクイズ問題を生成できます。時事クイズではTavilyの検索結果を参考に、指定期間内の出来事を扱います。メモ取り込みでもウェブ検索を利用できます。

- **AI解説補完**  
  解説がない問題に対して、AIで解説を追加できます。問題編集の「AI解説を再セット」では、従来の標準パターンを含む次の作成パターンを選べます。
  - **標準（従来）**: 関連知識や背景知識を含む、簡潔な解説を作成します。
  - **小中学生向けに解説**: 小中学生にも伝わる言葉を使い、難しい用語は避けるか、簡単に説明します。既存の解説があれば、その要点や事実関係を保って書き直します。
  - **ジャンル初心者向けに解説**: 鉄道、コスメ、ファッション、アイドルなど、対象ジャンルに詳しくない一般読者に向けて、理解に必要な用語や分類、慣習、背景を補足します。性別・年齢・趣味から知識や関心を決めつけません。
  - **理系問題を文系向けに解説**: 数式や理系の専門用語を日常的な言葉に置き換えるか、簡潔に説明します。
  - **問題文の前振り・手掛かりを解説**: 前振りに登場する語句の意味や背景、関連知識を中心に説明します。問題の構造や解答に至る推理過程ではなく、語句にまつわる知識を広げる構成です。

  標準以外のパターンは、標準モードの通常の解説の1.5倍以内を目安に、本文は1〜2文、暗記のコツを含め全体を2〜3文で作成します。

- **ジャンル自動判定**  
  未分類の問題に対して、AIでジャンルとサブジャンルを判定できます。

- **読み上げ辞書**  
  人名・地名・専門用語など、読み間違えやすい語の読み方を登録できます。
  問題詳細の「読み方を一括設定」では、問題文中の括弧書きから読み方を抽出し、選択した括弧書きを問題文から削除できます。

- **MP3音声作成**  
  Google Cloud Text-to-Speech APIを利用し、問題・解答・解説を読み上げるMP3ファイルを作成できます。問題文は全文を読むほか、確定ポイントまで読んで3秒後に続きを読み、全文の後に1秒休止して解答を読むモードと、確定ポイントの3秒後に解答を読むモードを選べます。

- **学習分析**  
  正解率、未回答数、解説なし問題数、ジャンル別分析などを確認できます。

### AIによる分類

- **AI問題生成** では、ジャンルを指定すると、そのジャンルに属するサブジャンルだけを選択できます。ジャンルを指定しない場合は、入力したテーマに合う候補が自動選択されます。
- **問題管理** の問題詳細では、問題文と解答をもとに1問ずつジャンル・サブジャンルを自動判定できます。
- **ジャンル一括自動判定** では、現在の学習セットにあるジャンル未設定の問題を、1回につき最大30問まで判定できます。残りの問題は再度実行してください。
- AIが判定した分類は必ず確認してください。候補に迷う問題は最も近い分類が選ばれるため、問題詳細画面で手動修正できます。

ジャンルが未設定の問題は「未設定」として管理され、ジャンル別分析の対象外になります。サブジャンルだけを単独で設定することはできません。

## 使い方

### 1. ファイルを開く

このアプリは静的なHTMLアプリです。リポジトリを取得したら、`index.html` をブラウザで開きます。

```bash
git clone <repository-url>
cd <repository-name>
```

ローカルでそのまま開けますが、ブラウザやAPI利用条件によってはローカルサーバー経由で開く方が安定します。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

### 2. APIキーを設定する

AI機能や音声作成機能を使う場合は、画面右上の **設定** からAPIキーを登録します。

| キー | 用途 |
|---|---|
| Gemini APIキー | AI問題生成、CSV取り込み時のAI解説生成、SSMLふりがな付与（利用モデル: gemini-3.8-flash） |
| Tavily APIキー | 時事クイズとメモ取り込みのウェブ検索 |
| Google Cloud Text-to-Speech APIキー | MP3音声ファイルの作成 |

APIキーはブラウザのLocalStorageに保存されます。設定画面では初期状態ですべてマスキングされ、「すべてのAPIキーを表示する」で一括して表示を切り替えられます。設定画面を開き直すと再びマスキングされます。

### 3. 問題を登録する

#### CSVから登録

CSVは以下の列構成で作成します。

```csv
問題文,解答,解説
日本で最も高い山は何でしょう？,富士山,日本最高峰の山で、標高は3776mです。
```

- 1列目: 問題文
- 2列目: 解答
- 3列目: 解説

解説が空欄の場合、Gemini APIキーを設定していればAIで解説を補完できます。

#### AIで生成

**AI問題生成** 画面から、ジャンル、サブジャンル、難易度、生成件数を指定して問題を作成できます。

**時事クイズ** は通常生成の生成モードで選択し、1週間、2週間、1か月、3か月、6か月、1年から遡る期間を指定します。端末の当日を含む期間を使い、月単位は暦月で計算します。ジャンルやテーマを指定せずに生成することもできます。検索資料に基づく出来事の日付が期間内と判定された案のみ採用し、資料のURLを問題とともに保存します。資料は問題詳細で確認できます。資料が不足した場合などは指定数に満たないことがあります。
ジャンル・テーマを指定しない時事生成では、訃報も追加検索し、適切な資料がある場合は10問あたり1〜2問程度以上を目安に候補へ含めるよう指示します。件数や採用は保証されません。追加検索にも料金が発生する場合があります。
参考資料はCSVには含まれません。

**メモ取り込み** では「ウェブ検索で最新情報を参照する」を有効にすると、名称補正と問題作成の両方で検索し、選択した期間内の出来事を扱う時事クイズを作成します。期間は通常生成と同じ6種類から選べ、初期値は1年です。たとえば「硤合憲三　2026年ノーベル化学賞」のように補足事項を入れ、補正結果と生成結果を確認してください。対象や補足事項に合う期間内の出来事を確認できない候補はエラーとして表示します。検索を使わない従来の生成も引き続き利用できます。

時事問題では、資料から確認できる中心的な出来事の年月日を問題文に含めるようAIに指示します。年月日を含む日付は原則1回とし、期間や複数の日付自体を問う場合など必要なときは例外とします。年だけの手掛かりは別扱いです。年月日や文章の正確さは保証されないため、必ず参考資料と照らし合わせてください。
訃報では死亡日、死去の発表日、死去が報じられた日を区別し、死因や年齢は資料で確認できる場合だけ記載するよう指示します。中心となる事実の日付を期間判定に使いますが、日付や死因の正しさは自動保証されません。

時事問題は、背景から時事の手掛かりへ絞り込む構成とし、問題文60〜110文字、解説100文字以内で作成します。文字数や生成情報が条件を満たさない結果は除外され、指定数未満となることがあります。生成結果には解答の読み、別解、基準年月、問題タイプ、関連タグを付けます。読みは問題固有の読み上げ設定に保存されるため、別解とともに問題詳細で必ず確認・修正してください。別解は解答表示時の参考情報であり、自動採点は行いません。基準年月などの生成情報と参考資料はCSVには含まれません。

検索にはTavily APIキーとGemini APIキーが必要です。検索語はTavilyへ、検索結果はGeminiへ送信され、検索と生成の回数に応じた利用料金が発生する場合があります。メモには機密情報や個人情報を入力しないでください。検索結果や生成内容は誤りを含む場合があり、検索記事の公開日と出来事の日付も異なるため、保存後も出典と問題の内容を確認してください。記事の著作権や利用条件は各提供元のものです。

### 問題管理の各機能

「問題管理」には、**管理・分析**、**問題一覧・個別編集**、**問題一括編集**、**セット統合**のタブがあります。

#### 管理・分析

学習セットの作成・名称変更・削除、順序変更、ピン留めができます。選択中のセットの問題数、正解率、習熟度、解説・ジャンル未設定数や、正解率／習熟度・ジャンル別の分析を確認できます。問題整理では、習熟度または正解率の高い問題を上位割合か指定問題数で削除できます。また、セット内の問題だけをすべてリセットする機能もあります。

#### 問題一覧・個別編集

セットを選び、問題文・解答・解説・ジャンルなどの検索、ジャンル／サブジャンル／習熟度による絞り込みができます。詳細画面では問題文、解答、解説、ジャンル、サブジャンル、確定ポイントを編集し、問題や解答の再作成、ジャンル判定、読み上げ設定ができます。詳細画面から問題の別セットへの移動や削除も行えます。

#### AI解説補完

問題詳細の解説欄で作成パターンを選び、「AI解説を再セット」を押すと、問題文と解答をもとに解説を生成して編集欄に反映します。生成結果を保存するには、詳細画面の「保存する」を押してください。

##### 標準（従来）

関連知識や背景知識を含む、従来どおりの簡潔な解説を作成します。

##### 小中学生向けに解説

小中学生にも伝わる言葉を使い、難しい用語は避けるか、簡単に説明します。既存の解説がある場合は、要点や事実関係を保って書き直します。

##### ジャンル初心者向けに解説

鉄道、コスメ、ファッション、アイドルなど、対象ジャンルに詳しくない一般読者向けに、必要な用語・分類・慣習・背景を補足します。性別や年齢などから知識や関心を決めつけません。

##### 理系問題を文系向けに解説

理系の予備知識がない読者にも分かるよう、数式や専門用語を日常的な言葉に置き換えるか、簡潔に説明します。

##### 問題文の前振り・手掛かりを解説

前振りに登場する語句の意味や背景、関連知識を中心に話を広げます。問題の構造や解答に至る推理過程ではなく、語句にまつわる知識を解説します。

標準以外のパターンは、標準モードの通常の解説の1.5倍以内を目安に、本文は1〜2文、暗記のコツを含め全体を2〜3文で作成します。

解説未設定の問題は、問題一覧の「AI解説一括作成」から優先度順に最大15問までまとめて補完できます。個別生成・一括生成のいずれもGemini APIキーが必要です。

#### 重複問題を一括チェック

問題文と解答が一致する問題は自動でまとめ、成績を合算します。同じ解答で問題文が異なる問題は候補を表示し、残す問題を選ぶか、統合せず残すかを指定できます。

#### 問題一括編集

セット内の問題を選び、まとめて削除したり別のセットへ移動したりできます。選択は20問ずつのページ単位で行えます。移動先のセット上限を超える場合は移動できません。

#### AIによる一括ジャンル判定

ジャンル未設定の問題は1回あたり最大30問までジャンル・サブジャンルを判定できます。Gemini APIキーが必要です。

#### 学習セットを統合する

1. **問題管理** を開き、「セット統合」タブを選びます。
2. **統合元の学習セット** と **統合先の学習セット** を選びます。統合元の問題は統合先へ移動します。
3. **統合後のセット名** を確認・編集します。初期値は統合先のセット名で、統合先を変更すると入力欄もそのセット名に更新されます。
4. 問題数と名称を確認して **学習セットを統合** を押し、確認ダイアログで実行します。

統合元のセットは削除され、問題の成績や解説などは引き継がれます。統合先の出題サイクル情報はリセットされ、同一問題がある場合も自動削除されず重複したまま残ります。統合後に統合先が1セットあたりの上限（1,500問）を超える場合は実行できません。

### 4. トレーニングする

ダッシュボードで対象セットを選択し、**トレーニング開始** を押します。

- 問題文はブラウザの音声合成で読み上げられます。
- 早押しボタンを押すと問題文が表示されます。
- ダッシュボードで「確定ポイントモード」を有効にすると、音声・文章モードとも問題ごとの確定ポイントまで出題します。無効時は問題文全体を使います。
- 解答表示後に、正解・不正解・スキップを記録できます。

| キー | 操作 |

## CSVフォーマット

### 問題CSV

| 列 | 内容 | 必須 |
|---|---|---|
| 1 | 問題文 | 必須 |
| 2 | 解答 | 必須 |
| 3 | 解説 | 任意 |

対応文字コード:

- UTF-8
- Shift-JIS

### 読み上げ辞書CSV

| 列 | 内容 |
|---|---|
| 1 | 単語 |
| 2 | 読み方 |

例:

```csv
単語,読み方
徳川家康,とくがわいえやす
```

辞書CSVはUTF-8で取り込みます。

## データ保存

アプリのデータはブラウザのLocalStorageに保存されます。主な保存対象は以下です。

- 学習セットと問題データ
- 読み上げ辞書
- 日別の回答数
- Gemini APIキー
- Google Cloud Text-to-Speech APIキー

ブラウザのデータ削除や別ブラウザへの移動により、保存データが失われる場合があります。重要な問題や辞書はCSVでバックアップすることをおすすめします。

## 登録上限

実装上、以下の上限が設定されています。

| 項目 | 上限 |
|---|---:|
| 学習セット数 | 10セット |
| 1セットあたりの問題数 | 1,500問 |
| アプリ全体の問題数 | 10,000問 |
| 学習セット名 | 30文字 |
| ジャンル一括自動判定 | 1回あたり30問 |
| CSV取り込み時のAI解説生成 | 最大15問 |

## 音声作成について

音声作成では、選択した学習セットから問題をランダムに選び、以下の流れで読み上げ音声を生成します。

1. 「問題」または「最終問題です」
2. 問題文
3. 解答
4. 解説

解説を読み上げるかどうかは、音声作成画面で切り替えられます。生成後はブラウザで再生し、MP3として保存できます。

ブラウザの読み上げと音声作成では、「漢字（かな）」のように漢字の直後に読みが括弧書きされている場合、括弧内の読みを優先し、括弧書き自体は重ねて読み上げません。

## 注意事項

- APIキーはブラウザのLocalStorageに保存されます。公開端末や共有端末での利用には注意してください。
- AI生成結果は必ずしも正確とは限りません。公開・配布前に問題文、解答、解説を確認してください。
- Text-to-Speech APIを利用するには、Google Cloud側でText-to-Speech APIが有効化されたAPIキーが必要です。
- このREADMEは `index.html` の実装内容をもとに作成しています。UIや機能を変更した場合はREADMEも更新してください。
