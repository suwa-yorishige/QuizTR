# 時事クイズ作問ガイドライン（AI生成仕様書）

## 1. 基本理念
時事クイズは単なる「ニュースの暗記テスト」ではなく、**「最新の出来事を入り口に、背景にある教養や文脈を推測させる知的ゲーム」**として設計する。ニュースを熱心に追っていないプレイヤーでも、問題文中のヒント（前振り）から論理的に正解を導き出せる構成を目指す。

---

## 2. 問題文の構造ルール（フリの構成）
読み上げ・早押し・一問一答のいずれにも耐えうるよう、原則として**「前振り（背景・文脈）＋ 後振り（時事的確定情報）＋ 問い」**の3段構成を採用する。

1. **前振り（導入・ヒント）**
   - ニュースの核となる固有名詞をすぐに出さず、その事象の「背景」「歴史的経緯」「意外なエピソード」「定義」から書き始める。
   - プレイヤーに「どの分野の話か」を推測させる余白を作る。
2. **後振り（絞り込み・時事フック）**
   - 「2026年〇月に〜」「史上初めて〜」「〜として社会現象となった」など、時事的な決定打となる事実を提示し、正解を1つに確定させる。
3. **問い（結び）**
   - 疑問詞（「誰でしょう？」「何でしょう？」「どこでしょう？」など）は明確にし、一問一答形式でスパッと終わらせる。
   - 問題文は選択した長さ（短め40〜60文字、標準60〜80文字、長め80〜120文字）に収め、冗長な修飾語は削ぎ落とす。初期値は標準で、選択範囲外の時事問題は除外する。

### 構成の比較例
* **悪い例（ストレート要約型）**
  > 2026年10月にノーベル生理学・医学賞を受賞した、マイクロRNAを発見したアメリカの科学者は誰でしょう？
  *(※冒頭で答えのジャンルが割れすぎており、後半の情報が蛇足になっている)*

* **良い例（競技クイズ・文脈接続型）**
  > 線虫の研究を通じて遺伝子の働きを制御する小さな分子を発見し、2026年10月にヴィクター・アンブロスとともにノーベル生理学・医学賞を受賞したアメリカの生物学者は誰でしょう？
  *(※「線虫の研究→遺伝子制御→2026年ノーベル賞→共同受賞者」と段階的に絞り込める)*

---

## 3. 作問の3つのアプローチ（問題タイプ）
入力されたニュースソース（記事テキストやトピック）の性質に応じて、以下のいずれかのパターンを選択して作問する。

* **タイプA：時事×一般教養ハイブリッド型（最優先）**
  - 最新のニュースを前振りにしつつ、**正解は普遍的な固有名詞（既存の歴史・地理・科学・文化用語など）**に着地させる。
  - *メリット：* ニュースの鮮度が落ちた後も、アプリ内の「一般教養問題」として長く資産化できる。
* **タイプB：ニュースバリュー・記録型**
  - 「観測史上初」「〇年ぶり」「法改正による新制度」など、そのニュースが報じられた最大の理由（フック）を問う。
* **タイプC：ストレート・人物／事象特定型**
  - 話題の人物、新語・流行語、ヒット作品、重要イベントそのものを問う。

## 4. 品質担保とリスク回避の厳格ルール

### ① 時間軸の固定（アンカリング）
* **禁止表現:** 「今年」「今月」「現在」「最近」「先日」などの相対的な時間表現は**原則使用禁止**とする。
* **推奨表現:** 必ず「2026年11月」「2026年度」のように絶対的な年月を明記し、時間が経過しても問題文の正誤が揺らがないようにする。

### ② 別解・表記揺れの網羅
* 音声読み上げ（TTS）やテキスト入力判定を考慮し、正解データには必ず以下のメタデータを付随させる。
  - **正解表記:** 最も一般的・正式な表記（例：`人工知能`）
  - **読み仮名:** ひらがな・カタカナでの正確な読み（例：`じんこうちのう`）
  - **許容別解:** 略称、英語表記、報道での通称など（例：`AI`, `Artificial Intelligence`）

### ③ 事実の確定性と中立性
* 推測・噂・未確定の予定（「〜する見通し」「〜と報じられた」）を断定形で出題しない。公式発表や確定した事実のみを根拠とする。
* 政治・思想・事件などを扱う場合は、特定の立場に偏らず客観的事実（数値、役職、法制度、歴史的経緯）のみを問う。

## 5. 出力フォーマット（システム連携用データ構造）
AIは作問時、以下の構造化された項目をセットで出力すること。

* **問題文:** （選択した文字数範囲内）
* **正解:** （原則1語〜短いフレーズ）
* **読み仮名:** （ひらがな）
* **別解リスト:** （配列形式）
* **基準年月:** （YYYY-MM形式）
* **問題タイプ:** （タイプA / タイプB / タイプC）
* **関連ジャンルタグ:** （例：政治・経済、科学・自然、スポーツ、エンタメ、歴史・地理）
* **解説（100文字以内）:** （正解の補足や、ニュースの背景となる豆知識）
