# QuizTR

早押しクイズ形式で知識を定着させる、ブラウザ完結型の学習アプリです。問題のCSV取り込み、AIによる問題生成・解説補完、読み上げ辞書、MP3音声作成、正解率に応じた復習などを1つの `index.html` で利用できます。

## 特徴

- **早押しクイズ学習**  
  ブラウザの音声合成で問題を読み上げ、早押しボタンで回答フェーズに進みます。

- **学習セット管理**  
  複数の学習セットを作成し、セットごとに問題を管理できます。

- **CSV取り込み**  
  問題文・解答・解説をCSVから一括登録できます。UTF-8 / Shift-JISの読み込みに対応しています。

- **AI問題生成**  
  Gemini APIを利用して、ジャンル・サブジャンル・難易度を指定したクイズ問題を生成できます。

- **AI解説補完**  
  解説がない問題に対して、AIで簡潔な解説を追加できます。

- **ジャンル自動判定**  
  未分類の問題に対して、AIでジャンルとサブジャンルを判定できます。

- **読み上げ辞書**  
  人名・地名・専門用語など、読み間違えやすい語の読み方を登録できます。

- **MP3音声作成**  
  Google Cloud Text-to-Speech APIを利用し、問題・解答・解説を読み上げるMP3ファイルを作成できます。

- **学習分析**  
  正解率、未回答数、解説なし問題数、ジャンル別分析などを確認できます。

## 使い方

### 1. ファイルを開く

このアプリは静的なHTMLアプリです。リポジトリを取得したら、`index.html` をブラウザで開きます。

```bash
git clone <repository-url>
cd <repository-name>
```

ローカルでそのまま開けますが、ブラウザやAPI利用条件によってはローカルサーバー経由で開く方が安定します。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

### 2. APIキーを設定する

AI機能や音声作成機能を使う場合は、画面右上の **設定** からAPIキーを登録します。

| キー | 用途 |
|---|---|
| Gemini APIキー | AI問題生成、CSV取り込み時のAI解説生成、SSMLふりがな付与 |
| Google Cloud Text-to-Speech APIキー | MP3音声ファイルの作成 |

APIキーはブラウザのLocalStorageに保存されます。

### 3. 問題を登録する

#### CSVから登録

CSVは以下の列構成で作成します。

```csv
問題文,解答,解説
日本で最も高い山は何でしょう？,富士山,日本最高峰の山で、標高は3776mです。
```

- 1列目: 問題文
- 2列目: 解答
- 3列目: 解説

解説が空欄の場合、Gemini APIキーを設定していればAIで解説を補完できます。

#### AIで生成

**AI問題生成** 画面から、ジャンル、サブジャンル、難易度、生成件数を指定して問題を作成できます。

### 4. トレーニングする

ダッシュボードで対象セットを選択し、**トレーニング開始** を押します。

- 問題文はブラウザの音声合成で読み上げられます。
- 早押しボタンを押すと問題文が表示されます。
- 解答表示後に、正解・不正解・スキップを記録できます。

## ショートカットキー

クイズ画面では以下のキーが使えます。

| キー | 操作 |
|---|---|
| Space | 出題中は早押し、問題文表示中は解答を表示 |
| T | 正解として記録 |
| F | 不正解として記録 |
| S | スキップ |
| G | 解説がない問題にAI解説を追加 |
| Esc | クイズを終了してホームに戻る |

## CSVフォーマット

### 問題CSV

| 列 | 内容 | 必須 |
|---|---|---|
| 1 | 問題文 | 必須 |
| 2 | 解答 | 必須 |
| 3 | 解説 | 任意 |

対応文字コード:

- UTF-8
- Shift-JIS

### 読み上げ辞書CSV

| 列 | 内容 |
|---|---|
| 1 | 単語 |
| 2 | 読み方 |

例:

```csv
単語,読み方
徳川家康,とくがわいえやす
```

辞書CSVはUTF-8で取り込みます。

## データ保存

アプリのデータはブラウザのLocalStorageに保存されます。主な保存対象は以下です。

- 学習セットと問題データ
- 読み上げ辞書
- 日別の回答数
- Gemini APIキー
- Google Cloud Text-to-Speech APIキー

ブラウザのデータ削除や別ブラウザへの移動により、保存データが失われる場合があります。重要な問題や辞書はCSVでバックアップすることをおすすめします。

## 登録上限

実装上、以下の上限が設定されています。

| 項目 | 上限 |
|---|---:|
| 学習セット数 | 10セット |
| 1セットあたりの問題数 | 1,500問 |
| アプリ全体の問題数 | 10,000問 |
| 学習セット名 | 30文字 |
| ジャンル一括自動判定 | 1回あたり30問 |
| CSV取り込み時のAI解説生成 | 最大15問 |

## 音声作成について

音声作成では、選択した学習セットから問題をランダムに選び、以下の流れで読み上げ音声を生成します。

1. 「問題」または「最終問題です」
2. 問題文
3. 解答
4. 解説

解説を読み上げるかどうかは、音声作成画面で切り替えられます。生成後はブラウザで再生し、MP3として保存できます。

## 注意事項

- APIキーはブラウザのLocalStorageに保存されます。公開端末や共有端末での利用には注意してください。
- AI生成結果は必ずしも正確とは限りません。公開・配布前に問題文、解答、解説を確認してください。
- Text-to-Speech APIを利用するには、Google Cloud側でText-to-Speech APIが有効化されたAPIキーが必要です。
- このREADMEは `index.html` の実装内容をもとに作成しています。UIや機能を変更した場合はREADMEも更新してください。
